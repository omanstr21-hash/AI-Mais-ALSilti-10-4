مشروع الصف العاشر: الذكاء الاصطناعي في حياتنا

طريقة التشغيل:
1- فك ضغط ملف ZIP.
2- افتح المجلد في Visual Studio Code.
3- افتح index.html باستخدام Go Live (إضافة Live Server) أو افتح index.html مباشرة في المتصفح.
4- للتسليم، املأ استمارة_المشروع.txt واطبع site-map.html أو أرفق site-map.txt.

محتويات المشروع: 4 صفحات رئيسية/فرعية + صفحة مخطط الموقع + style.css + 4 رسومات SVG أصلية محلية في assets.

ملاحظة: جميع الصور محلية وتعمل دون إنترنت. خط Cairo يتحمّل من Google Fonts عند وجود اتصال، وإلا تظهر خطوط النظام البديلة.

معايير التقييم: عنوان، شريط تنقل، خط فاصل، روابط تشعبية، وسائط متعددة (صور)، فقرات، CSS، قائمة، جدول، Go Live، مخطط موقع.

إعداد الطالبة: ميس الصلتي
الصف: العاشر / 4

تمت إضافة فيديو توضيحي أصلي صامت مدته 12 ثانية ونغمة ترحيبية صوتية مستقلة إلى الصفحة الرئيسية، وتعمل الوسائط دون إنترنت.
